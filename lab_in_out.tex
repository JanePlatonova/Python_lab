
\chapter{Лабораторна робота 1\\ Лінійні алгоритми}
Під час виконання лабораторної роботи з теми \textbf{<<Лінійні алгоритми>>} зверніть увагу на такі рекомендації:
\begin{enumerate}[label=\arabic*.]
	\item \textbf{Введення даних та перетворення типів:}
	\begin{itemize}
		\item Для отримання текстових даних використовуйте функцію \texttt{input()} (наприклад: \texttt{name = input("Ваше ім'я: ")}).
		\item Для цілих чисел (номери, лічильники, виділення окремих цифр числа) застосовуйте перетворення \texttt{int(input())}.
		\item Для дійсних чисел (дробові значення у формулах, радіуси, довжини) використовуйте \texttt{float(input())}.
	\end{itemize}
	\item \textbf{Цілочислова арифметика для роботи з цифрами числа:}
	\begin{itemize}
		\item Остачу від ділення \texttt{\%} використовують для отримання останньої цифри: \texttt{last = n \% 10}.
		\item Цілочислове ділення \texttt{//} використовують для відкидання останньої цифри: \texttt{n = n // 10}.
		\item Збирання нового числа з отриманих цифр виконується за позиційним принципом: наприклад, \texttt{num = a * 100 + b * 10 + c}.
	\end{itemize}
	\item \textbf{Використання математичних функцій (модуль \texttt{math}):}
	\begin{itemize}
		\item Перед використанням математичних функцій підключіть модуль командою \texttt{import math}.
		\item Квадратний корінь $\sqrt{x}$: \texttt{math.sqrt(x)}.
		\item Натуральний логарифм $\ln x$: функція \texttt{math.log(x)} (\textit{зверніть увагу: не \texttt{ln()}}).
		\item Тригонометричні функції: \texttt{math.sin(x)}, \texttt{math.cos(x)} (аргумент $x$ задається виключно в радіанах).
		\item Переведення градусної міри в радіани: \texttt{math.radians(deg)} або виразом \texttt{deg * math.pi / 180}.
		\item Число $\pi$: константа \texttt{math.pi}.
		\item Модуль числа $|x|$: вбудована функція \texttt{abs(x)} або \texttt{math.fabs(x)}.
	\end{itemize}
	\item \textbf{Виведення результатів та форматування:}
	\begin{itemize}
		\item Супроводжуйте кожне виведення зрозумілим текстовим поясненням: \texttt{print("Результат:", z)}.
		\item Якщо в умові вимагається точність до сотих, використовуйте f-рядки: \texttt{f"\{z:.2f\}"} або функцію \texttt{round(z, 2)}.
	\end{itemize}
\end{enumerate}
