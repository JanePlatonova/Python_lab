## 1. ЗАГАЛЬНА ХАРАКТЕРИСТИКА ТА ОСНОВНІ СИСТЕМНІ ПРОБЛЕМИ

Проведений комплексний філологічний, науково-редакторський та термінологічний аналіз усіх семи файлів лабораторних робіт (`lab_in_out.tex`, `lab_python_if_1.tex`, `lab_if_2.tex`, `lab_python_if.tex`, `lab_for1.tex`, `lab_for2.tex`, `lab_while.tex`), а також супровідного титульного файлу `titul12.tex`, що включені до `main.tex`.

У цілому матеріал становить собою якісну підбірку задач із програмування, проте мовне оформлення містить значну кількість суттєвих відхилень від норм сучасної української літературної та науково-технічної мови. Виявлено низку системних помилок, які повторюються у десятках варіантів:

1. **Неперекладені фрагменти російською мовою**:
   У файлі `lab_while.tex` виявлено цілі рядки, речення та окремі задачі, залишені російською мовою (наприклад, задачі на обчислення границі та задача «Интересный квадрат», фрази «с заданной точностью» тощо). Це свідчить про незавершений процес перекладу/адаптації першоджерела.
2. **Невдалий машинний переклад та лексичні курйози**:
   - «За перебування 45-го простого числа» замість «За відшукання / знаходження» (машинна калька рос. «за нахождение», сплутаного з «пребывание»);
   - «Яка кількість знайшов Ейлер?» замість «Яке число знайшов Ейлер?» (калька з «Какое число нашел Эйлер?»);
   - «Теоретично чисел» замість «У теорії чисел» (калька рос. «В теории чисел»);
   - «Твір цифр» замість «Добуток цифр» (калька рос. «Произведение цифр»);
   - «Вів величезну листування ... Декарт та інші ... теоретично музики» замість середнього роду «велике листування», орудного відмінка «Декартом та іншими» та «у теорії музики»;
   - «потрійними непарними» замість «непарними, кратними трьом».
3. **Ненормативна математична та комп'ютерна термінологія**:
   - Системне вживання калькованих прикметників «тризначне», «чотиризначне», «двозначне», «шестизначне» замість питомих і стандартних термінів: **трицифрове**, **чотирицифрове**, **двоцифрове**, **шестицифрове** (число складається з цифр, а знаки — це будь-які символи);
   - «вірно / вірні знаки» замість нормативного **правильно / правильні десяткові знаки (цифри)**;
   - «приймає значення» замість нормативного математичного **набуває значень**;
   - «вирішення завдання / проблеми» замість **розв'язання задачі**;
   - «рівняння» для позначення нерівності $(x-a)^2 + (y-b)^2 \le R^2$;
   - «витягти кубічний корінь» замість **добути кубічний корінь**;
   - «складові числа» замість **складені числа** (composite numbers);
   - «$q$-їчна система числення» замість **$q$-кова**;
   - «однозначні числа» замість **одноцифрові**.
4. **Граматичні, словотвірні та синтаксичні дефекти керування**:
   - Масове помилкове утворення дієприслівника: «округляючи» замість нормативного **округлюючи** (від дієслова «округлювати»);
   - Помилкове безприйменникове керування дієслова: «запитує користувача» замість **запитує в (у) користувача**;
   - Порушення відмінкового узгодження: «число ... її найбільшу цифру» замість «його»; «$M_n$ є простою» замість «є простим»; «запитує назва» замість «назву»; «ВНЗ, в якій» замість «в якому»; «Яка відстань пробіжить» замість «Яку відстань»;
   - Помилки керування прийменників напрямку: «на початку числа» замість «на початок числа», «перевести на радіани» замість «у радіани»;
   - Калька російського прийменника «по»: «по заданим радіусам» замість «за заданими радіусами»;
   - Калька конструкції «при»: «при рівності очок» замість «у разі рівності очок», «при читанні» замість «під час читання».
5. **Стилістичні штампи та канцеляризми**:
   - «повідомлення виду: ...» замість **повідомлення такого вигляду:** або **на зразок:**;
   - «Відома наступна закономірність:» замість **Відома така закономірність:**;
   - «У ході діалогу» замість **Під час діалогу**;
   - «Що являє собою...» замість **Чим є...** або **Що становить собою...**.
6. **Типографічні дефекти та синтаксичні помилки LaTeX**:
   - Помилка форматування `\ verb |`, що розбиває макрос;
   - Загублений тег виноски: `ootnote[1]` замість `\footnote[1]`;
   - Пропущена відкриваюча дужка `\footnote{`, що призвела до злиття тексту виноски з умовою задачі та появи сирої закриваючої дужки `}.` (Лаб 1, вар. 9);
   - Опечатка «ЗЗа знаходження» (подвоєна літера З);
   - Крапка замість знака питання наприкінці питальних речень;
   - Формула `$pi $` без бекслеша замість `$\pi$`;
   - Дефіс у слові «ком-п'ютер», залишений після ручного переносу.

## 3. ЗВЕДЕНИЙ СЛОВНИК-ГЛОСАРІЙ ТИПОВИХ ЗАМІН ДЛЯ АВТОРІВ ТА РЕДАКТОРІВ

| Помилково / Кальковано | Нормативний академічний варіант | Коментар / Обґрунтування |
| :--- | :--- | :--- |
| **тризначне, чотиризначне, двозначне число** | **трицифрове, чотирицифрове, двоцифрове число** | Число складається з цифр; знаки — це будь-які символи (+, -, літери тощо). |
| **чи вірно, що...** | **чи правильно, що... / чи правда, що...** | «Вірно» — віддано, незрадливо. Істинність судження позначається словом «правильно». |
| **округляючи** | **округлюючи (округливши)** | Нормативне дієслово — округлювати. Дієприслівник недоконаного виду — округлюючи. |
| **запитує користувача** | **запитує в (у) користувача** | Дієслово запитувати вимагає прийменникового додатка. |
| **по заданим радіусам / по формулі** | **за заданими радіусами / за формулою** | Прийменник «по» не вживається на позначення підстави, критерію чи відповідності. |
| **приймає значення** | **набуває значень** | Математична функція, змінна або поліном набуває значень. |
| **вирішення задачі / проблеми** | **розв'язання задачі** | Задачі в математиці розв'язують; вирішують питання, долі або справи в суді. |
| **рішення диференціального рівняння** | **розв'язок диференціального рівняння** | Результат інтегрування рівняння є розв'язком. |
| **вірні знаки / символи** | **правильні (десяткові) знаки / цифри** | У метрології та чисельних методах використовують термін «правильні знаки». |
| **складове число** | **складене число** | Composite number — складене число (на противагу простому числу). |
| **витягти корінь** | **добути корінь** | Математична операція над радикалом — добування кореня. |
| **повідомлення виду** | **повідомлення такого вигляду / на зразок** | Канцеляризм, пряма калька російського «сообщение вида». |
| **відома наступна закономірність** | **відома така закономірність** | «Наступний» вказує на черговість у часі чи просторі, а не на подальший текст. |
| **у ході діалогу** | **під час діалогу** | Канцелярський штамп (калька з «в ходе»). |
| **що являє собою** | **чим є / що становить собою** | Калька з російського «представляет собой». |
| **при рівності** | **у разі рівності / за умови рівності** | Прийменник «при» з абстрактними іменниками є калькою російського звороту. |
| **однозначне число** | **одноцифрове число** | Однозначним може бути трактування; число з однієї цифри — одноцифрове. |
| **перевести на радіани** | **перевести в радіани** | Одиниці перетворюють або переводять «у щось». |
| **на початку числа (куди?)** | **на початок числа** | Напрямок переміщення вимагає знахідного відмінка («куди?», а не «де?»). |
| **більших 10** | **більших за 10 (від 10)** | В українській мові порівняльний ступінь потребує прийменників «за», «від», «ніж». |
| **півтора роки** | **півтора року** | Числівник «півтора» вимагає родового відмінка однини. |

| **уявлення числа сумою** | **подання числа у вигляді суми** | «Уявлення» — mental image/perception; математичне representation — подання. |
| **межа (limit)** | **границя (limit)** | У математичному аналізі послідовність прямує до границі (межа — це border/boundary). |

## 4. ПІДСУМОК ТА РЕКОМЕНДАЦІЇ ЩОДО ВИПРАВЛЕННЯ

1. **Файл `lab_while.tex`** потребує термінового доопрацювання та фінального редагування: перекласти неперекладені задачі та відновити зіпсований машинним перекладом зміст ряду завдань (особливо у виносках та формулюваннях прості/складені числа).

3. **Уніфікувати типографіку**: замінити подвійні дефіси `--` на нормативне довге тире `"---`, звести всі лапки до єдиного стандарту (`<< >>`), виправити поодинокі збої в коді LaTeX (`\footnote`, `\verb`).
